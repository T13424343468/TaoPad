# TaoPad 优化与功能规划

> 原则：先稳（真机验证通过再扩大战线）、先痛（用户实测反馈的优先）、先薄（每项可独立交付验证）。

## 一、现有功能优化（按优先级）

| 优先级 | 优化项 | 现状与做法 | 预估 |
|---|---|---|---|
| P0 | 大文件性能 | 着色全文一次完成；改为**可视区增量着色**（只格式化滚动可见范围，滚动时补着色） | 中 |
| P0 | RichEditBox 光标定位精度 | 等宽估算在比例缩放/非整数行高下有偏差；改用 `CharacterRange`/`ITextRange` 查询 + 校准系数 | 小 |
| P1 | 补全弹层定位 | 换行/自动换行时估算漂移；用 RichEditBox `GetRect` 类 API 取真实矩形（需验证 1.5 可用性） | 中 |
| P1 | 着色异步化 | >100KB 文档分块在后台线程分词，UI 线程只做格式化，避免长停顿 | 中 |
| P1 | 撤销体验 | 着色不占撤销栈（已隔离）；补全接受合并为一个撤销单元（已做 undo group，验证粒度） | 小 |
| P2 | 会话恢复增强 | 记录每个标签光标位置与滚动位置 | 小 |
| P2 | 主题色板抽取 | 三套主题色集中到一个配色表文件，便于扩展自定义主题 | 小 |

## 二、新增功能规划（按批次）

### 批次 A：编辑体验补全（近期）
1. **行号栏 + 当前行高亮**：Canvas 自绘行号（与内核无关），点击行号选中整行。
2. **当前行高亮与括号匹配高亮**：光标停留时对应括号对描色。
3. **Shift+Tab 反缩进**、**Alt+Up/Down 行移动**、**Ctrl+D 复制当前行**。
4. **正则查找替换**、**多文件（文件夹内）查找**：结果列表双击跳转。
5. **书签**：Ctrl+F2 打标/F2 跳转，书签列显示。

### 批次 B：语言与提示升级（中期）
1. **代码折叠**：按括号/缩进层级折叠区（RichEditBox 需折叠标记与渲染结合，需预研）。
2. **Snippet 模板**：输入 `for`+Tab 展开代码骨架，JSON 配置可扩展。
3. **参数提示浮层**：函数名后 `(` 触发参数说明。
4. **内置语言配置化**：关键字/注释规则用 JSON 定义，新语言零代码接入。

### 批次 C：平台能力（中期）
1. **文件监视**：外部修改提示重载（FileSystemWatcher + 时间戳校验）。
2. **只读模式与大文件模式**：>10MB 提示只读打开，保证不卡死。
3. **打印与导出 PDF**：着色保留（XAML 打印桥）。
4. **自动更新检查**：启动时拉版本清单，提示新版本下载。
5. **设置页 GUI 化**：字号/主题/缩进宽度/关联格式集中管理（当前靠配置文件）。

### 批次 D：进阶（长期）
1. **多光标/列选择**：WinUI 无原生支持，需在适配层实现多选区模拟，工作量最大。
2. **小地图（minimap）**：自绘缩略导航。
3. **简单语言服务**（LSP 客户端）：为 C#/Python 等接入语义补全与跳转定义。
4. **插件化**：脚本扩展菜单与命令（如 PowerShell）。

## 三、暂不做（明确排除）

- 自绘编辑器内核（成本/收益不匹配，双内核方案长期保留）。
- 工程级 IDE 能力（项目树/构建/调试）——与 TaoIDE 定位重叠，TaoPad 保持轻量编辑器。

## 四、验收口径（每个新功能）

1. 编译 0 错 0 警；逻辑层新增单测进 logictest。
2. 真机走"安装→使用→卸载重装"完整链路。
3. 版本号递增 + 更新日志同步。

## 多光标完整方案（v1.9 候选，批次 D 工作流补充）

v1.8 已交付务实降级版（BlockEditEngine 纯逻辑 + Alt+Shift+方向键列块视觉高亮 + Ctrl+Shift+L 词出现高亮）。
完整多光标在 WinUI 内核上的可行路径：

1. **多插入点状态层**：内核仍是单一 RichEditBox 选区，多光标作为虚拟插入点列表
   (List<int> carets) 维护在 CodeEditor 中；渲染层用 CharacterFormat 背景色模拟多光标线。
2. **编辑扇出**：任何文本修改按 carets 从后往前逐个应用（避免位置漂移），
   每次修改后按偏移增量平移后续插入点（参照 BlockEditEngine.Insert 的等量语义扩展）。
3. **键盘交互**：Ctrl+D 追加下一相同词虚拟光标、Alt+Click 添加/移除光点、
   Esc 收敛回单光标；输入/删除/撤销都要走扇出通道。
4. **撤销集成**：一次多光标编辑合并为一条撤销记录（差量撤销已有基础）。
5. **风险**：RichEditBox 无选区变化事件，虚拟光标与真实选区的同步要靠
   KeyUp/TextChanged/PointerReleased 兜底，输入法组合期间必须冻结扇出。
