# TaoPad 用户使用手册

## 1. 安装与启动

1. 运行 `build-installer.bat`（源码包内）生成安装包，或直接使用已发布的安装文件。
2. 双击 `TaoPad-1.7.0-x64.exe`，勾选许可协议、选好目录和文件关联，点"立即安装"。
3. 覆盖安装会自动清理旧版本，无需先卸载。安装包自带全部运行库，**不需要联网**。

## 2. 界面一览

- **顶部菜单**：文件 / 编辑 / 查找 / 视图 / 主题 / 帮助。
- **标签栏**：多文件同时编辑，改动未保存的标签标题带 ●。
- **编辑区**：代码文件自动语法着色 + 彩虹括号 + 智能提示。
- **状态栏**：行列位置、选中长度、字符数、编码、换行符、缩放比例。

## 3. 常用操作

| 操作 | 方式 |
|---|---|
| 打开文件 | Ctrl+O，或把文件拖进窗口 |
| 保存 / 另存为 | Ctrl+S / Ctrl+Shift+S |
| 查找 / 替换 | Ctrl+F / Ctrl+H（支持大小写、全词、循环） |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 缩放字号 | Ctrl+鼠标滚轮 |
| 自动换行 | 视图菜单切换 |
| 接受补全 | 回车或 Tab；上下键选择；Esc 关闭 |
| 格式化 | Ctrl+K 然后 Ctrl+D（全文）；Ctrl+K 然后 Ctrl+F（选区） |
| 缩进 | Tab（插入 4 空格，不会跳出编辑区） |
| 切换主题 | 主题菜单（水墨 / 浅色 / 深色），即时生效 |

## 4. 智能提示说明

- 在代码文件中输入标识符前 2 个以上字符自动弹出候选（关键字 + 文中已有词）。
- 候选与已输入内容完全相同时不会弹窗（没有可补的内容）。
- 代码着色在输入停顿约 0.2 秒后刷新；超大文件（>300KB）彩虹括号自动关闭以保证流畅。

## 5. 文件与编码

- 打开时自动识别 UTF-8 / UTF-8 BOM / GB 系 / UTF-16，状态栏显示当前编码。
- 保存时保持原编码与原换行格式（CRLF/LF/CR），不会悄悄改动。

## 6. 故障排查

- **双击打不开**：到 设置→应用 卸载所有旧版 TaoPad 后重装；若仍失败，把 `%LOCALAPPDATA%\TaoPad\crash.log` 发给开发者。
- **界面颜色异常**：主题菜单里切回"水墨"即可复位。
- **大文件变慢**：属正常保护策略（彩虹括号自动关闭）；继续增大时会自动简化着色。
