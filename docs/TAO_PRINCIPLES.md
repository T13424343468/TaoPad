# TaoPad 道法总纲

以道家思想为指导的工程总纲。八条原则各对应代码中的具体机制，是此后所有迭代的改造依据。
基调：**重构而不重来**——真机验证过的部分（水墨灰阶、主题一致性、图标链路、安装器路径、
设置弹窗）是根本，不动；改造只落在尚未合道之处。

## 一、道法自然 —— 顺应本来，不强造

**机制**：打开方式遵循平台惯例。文件关联双击即开、拖放即开、命令行转发给已有实例
（SingleInstance 命名管道），不另起进程；编码探测尊重文件本相（BOM 在则信 BOM），
不替用户做主转换。

## 二、无为而治 —— 不该管的不管，该兜底的兜住

**机制**：编辑逻辑不干预用户输入（无自动"纠正"）；框架异常一律拦截续命
（App.UnhandledException 记录不退出）；弹窗占用时新弹窗让位不报错
（ShowDialogSafe）；任何 UI 事件处理器失败不得中断主题/状态链。

## 三、上善若水 —— 处众人之所恶，故几于道

**机制**：脏活累活沉到看不见的层。编码读写、换行符差异、GBK/Big5 兜底、
崩溃转储（CrashLog/NativeCrashDump）、大文件只读降级——用户永远只见水面平静。

## 四、知常曰明 —— 唯一事实来源

**机制**：同一事实只写一处。
- **语言**：`LangDef.All` 是语言的唯一清单。语言菜单的项、文案、勾选目标全部由它
  动态生成（BuildLangMenu）；文件名识别（FromFileName）返回清单内同一实例——
  新增语言只改 Tokenizer 一处，菜单、识别、着色自动跟上。
  （v64 前：XAML 硬编码 13 项 + 控件名映射表，同一事实抄两处，已并。）
- **主题**：四套 Ant.*.xaml 键集合必须完全一致（95 键），由测试 K1 长期把守。
  任何一套缺键，切过去就静默回退兜底色——"负阴抱阳"，缺的那块是暗处，补齐才明。
- **校验**：扩展维度 K（K1 主题键一致 / K2 语言清单健全 / K3 识别与清单引用一致）
  常驻测试，违者测试红。

## 五、负阴抱阳 —— 有无相生

**机制**：空状态也是状态。无标签页有虚位以待的引导；菜单"最近文件"空时显示
"（空）"并禁用；主题字典里每套齐全，不留"别处有、此处无"的暗角。

## 六、周行而不殆 —— 循环往复，运转不息

**机制**：主循环不阻塞、不留死角。UI 线程绝不卡（绘制只画可见行、大文件降级）；
退出路径周全（最后窗口关闭 → 框架退出 → 1 秒兜底强杀，绝不留进程残留）；
主题切换对全窗口全弹窗生效，无一处遗漏。

## 七、功成身退 —— 事了身退，不居功

**机制**：临时资源用完即释：临时文件随生命周期释放、
弹层用毕复位（HideHint/HidePopup）、焦点用完归还编辑器（RestoreFocus——菜单操作后
打字立即有响应）。界面不留"刚才操作"的痕迹。

## 八、大道至简 —— 万事简洁，删繁就简

**机制**：能删的删，能并的并。v64 清理：语言菜单三处合一；主题补齐后不再需要
"取不到就兜底"的暗分支（兜底仍保留，作为最后防线，但常态不依赖）；
样式零死键（扫描证实 95 键全部有人引用）。命名见字明义，注释说人话。

---

## 改造守则（每次迭代前过一遍）

1. 真机验证过的行为，动了必须说明理由；
2. 新事实只能有一个来源，第二处引用必须动态取；
3. 主题三象（水墨/天青/墨夜）键集合不一致 = 不合格；
4. 编译错误数必须显式数到 0；全量测试必须全绿才发包。

# 附篇 · 测试之道 —— 道生一，一生二，二生三，三生万物

（Tao 系列统一标准，系列母本存于 tao-series 目录）

测试靠的不是手写堆用例，而是生成：用例由生成规则产生，覆盖面由组合保证。

- **道生一（本原）**：单字符宇宙 × 13 语言（维度 L1）——可打印 ASCII 全量 +
  全角/控制/零宽/组合字符 + emoji/ZWJ + RTL + 生僻 CJK，先证"一"之立得住；
- **一生二（两两组合）**：结构片段两两全组合（L2）；
- **二生三（三元矩阵）**：语言 × 编码 × 换行铺满（L3）；
- **三生万物（随机演化）**：固定种子随机生成，万物形态自行涌现（L4），
  归于一个总不变量——分词永不增删内容（L5 万物归一）。
- **断言之道**：属性式断言聚合计数，内部断言规模可见（当前 5395 条，L6）；
  暴力层四组（恶意模糊/属性不变量/压力/越界退化）每轮固定必跑。

# 附篇 · 样式之道 —— 万物各安其位

（Tao 系列统一标准附篇二。界面之乱不在不美，而在相侵；样式布局须机器可查，不靠目测。）

- **各安其位（零重叠）**：布局只走网格分行，不用画布绝对坐标；唯一的叠放
  （编辑器宿主铺底）有设计说明在案（M1）；
- **象必有名（名相齐全）**：图标链四查——程序图标、随包输出、窗口设置、
  卸载列表，一个不缺（M2）；
- **负阴抱阳（安顿有无）**：主题字典之外零硬编码色；"无标签"以自动新建安顿，
  永远不给用户一个空窗口（M3）；
- **知常守中（对齐有常）**：状态栏八项同字号同主题色，一族同制（M4）；
- **损之又损（布局可验）**：以上四查皆为常驻测试（扩展维度 M），与功能测试
  同轮全跑——样式之病与逻辑之病同罪。

# 附篇 · 主题三象 —— 道生一，一生二，一生三

（道生三象，只此三套，不再多设；全系 Tao 系列产品按此三套实现。）

- **水墨（默认，体）**：宣纸白底，墨分五色——浓墨关键字、重墨类型、
  正文标识符、淡墨数字字符串、灰墨预处理、最淡注释；纯灰阶，无一处暖色；
- **天青（昼，用）**：天青釉浅底 #EDF2EF（G>B>R，2026-11-06 全系 PC 统一），
  青瓷点缀 #2C534C——深藏蓝关键字、深青类型、暖赭字符串（冷暖相对）、青灰注释；
- **墨夜（夜，藏）**：暖炭底 #201E1B（非纯黑，R>G>B），宣纸白字 #E8E3D5
  主 / #ABA595 次，黛青点缀 #6FA3BC；语法色亮黛青关键字、青玉类型、
  暖沙字符串，与 TaoZip v53 墨夜母本同源；
- **三象之常**：决策唯一来源 ThemeRule 纯函数；三套字典键集合一致；
  三套语法色板与 ThemeRule 同值（O2 把关）；主题字典外零硬编码色不变。

# 附篇 · 模拟真人之道 —— 以人观象，万象可辨

（Tao 系列统一标准附篇三，2026-11-01 用户定：模拟真人操作 + 视觉观测暴露样式问题，全系同步。）

- **万象可辨（色彩距离）**：主题内全部语法元素与正文的色彩距离（RGB 欧氏）
  ≥ 40，关键字/注释 ≥ 60；同套之内不得有元素与正文混淆（S1 量化把关）；
- **模拟真人（操作链）**：万级随机操作链模拟真人切主题/看状态，断言每次
  切换后决策与基调一致、重复切换幂等（S2）；
- **视觉观测（以人观象）**：出主题包前渲染模拟界面图（代码高亮+行号+状态栏），
  由视觉模型逐套观测确认可辨后定稿；量化断言与视觉观测双重把关，缺一不发。

# 附篇 · 亮度阶梯 —— 三象各守其带

（Tao 系列统一标准附篇四，2026-11-01 用户定，母本 TaoZip v59，全系出包前落实。）

- **三带数值（母本）**：水墨暖宣浅底 #F7F5EE（L>0.8，R>G>B 暖序），点缀青灰蓝
  #52708A；天青釉浅底 #EDF2EF（L>0.85 且小于水墨，G>B>R），卡片面 #FAFCFA 亮于底
  （中调反转），文字深墨青 #1C242C/#3D4750，点缀深藏蓝 #0F4C9E，描边 #5E6870/#6E7880；
  墨夜以黑为主 #131211（L<0.03，暖序不灭），控件面 #211E1B，宣纸白 #E8E3D5/#ABA595
  与黛青 #6FA3BC 保留，描边 #6E675C/#5C574C。
- **断言要求**：三带 L 单调递减 + 冷暖序签名（暖·冷·暖）+ 点缀两两 WCAG 对比 ≥1.5；
  墨夜铁律为「以黑为主」。
- **可辨口径**：亮度档差或 RGB 色彩距离任一达标（彩色主题靠色相区分，纯亮度档差
  断言会假红）；中调底上语法色全套换深色系，浅底语法字不可用。
- **浅底系同色号**（2026-11-01 用户定）：水墨与天青等浅底主题，语法
  12 键同色号统一（深藏蓝关键字 #0F4C9E 等，母本见 TaoPad v72）；水墨底近白化
  （主底 #FCFBF7/控件面 #FEFDFB/描边 #ECEAE2）。墨夜黑底不可用深色字，按同色相
  亮版另行适配。
- **落实流程**：重设后全系全测（万链、模拟真人、视觉观测含所有样式与模拟真人
  操作留影），全绿才出包；各项目出包前按母本数值核对底色组。

# 附篇 · 避坑之道 —— 一处跌倒，全系筑栏

（Tao 系列统一纪律，2026-11-01 用户定：所有提交的 BUG，同系其它项目可能存在的同型问题全部避坑。）

- **同型排查**：收到真机 BUG 先归类（编译错/主题错/行为错/打包错），同型隐患逐项目
  排查，能写成断言的一律入链（沙箱即红），不等下一个真机暴露；
- **沙箱盲区**：沙箱不编译 App 工程——改界面侧代码必须通读上下文、源码级断言兜底
  （如 A1 引用自洽），出包整树同步，不做碎片式部分拷贝；
- **记录闭环**：避坑动作写各项目 goal.md，未落地记待办，忘排查看档。
