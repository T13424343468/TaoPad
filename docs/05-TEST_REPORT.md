## 5. 真机验收建议清单

1. 安装 1.7.0：确认"应用"列表只保留一个 TaoPad 条目。
2. 打开 >1 万行代码文件：着色完成时间可接受、滚动流畅。
3. 代码文件打字：候选框不闪烁；唯一候选=已输入词时不弹；多候选时 Tab/回车上词。
4. 编辑区按 Tab：插入缩进且焦点不动。
5. 切换主题来回：编辑区/弹层即时换色，提示不失效。
6. 故意制造崩溃（如超大文件极限操作）：crash.log 生成且有弹窗。
