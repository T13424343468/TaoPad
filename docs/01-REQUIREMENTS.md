# TaoPad 需求说明书

- 版本：1.7.0（文档与程序版本同步）
- 定位：Windows 桌面轻量级代码/文本编辑器，Notepad++ 的核心体验 + VS 风格智能提示，水墨视觉。
- 目标平台：Windows 10 1809+ / Windows 11，x64（源码支持 x86/ARM64）。
- 技术基线：.NET 8 + WinUI 3（Windows App SDK 1.5），非打包（unpackaged）分发。

## 功能需求（当前版本已实现）

### F1 文件与标签页
- F1.1 多标签编辑，标签可关闭、切换，显示修改状态（标题加 ●）。
- F1.2 新建/打开/保存/另存为，支持拖拽文件到窗口打开。
- F1.3 最近文件列表（记忆 10 条）。
- F1.4 会话恢复：退出时保存全部打开文件与活动标签，下次启动还原。
- F1.5 文本编码：自动识别 UTF-8/UTF-8 BOM/GB 系/UTF-16，读写保持一致；状态栏显示当前编码。
- F1.6 换行符：自动识别 CRLF/LF/CR，保存时按原格式还原。

### F2 编辑核心
- F2.1 双内核编辑区：纯文本/Markdown 用系统 TextBox；代码语言用 RichEditBox（支持着色）。
- F2.2 查找/替换（含大小写、全词、循环查找、全部替换）。
- F2.3 Ctrl+Z/Y 撤销重做、剪切/复制/粘贴/全选。
- F2.4 当前删除：删除当前行（Ctrl+Shift+K？见快捷键表）、复制当前行。
- F2.5 Tab 缩进：编辑区内 Tab 插入 4 空格，不转移焦点；补全弹层打开时 Tab 优先接受候选。
- F2.6 缩放：Ctrl+滚轮 调整编辑区字号（20%~400%），状态栏显示比例。
- F2.7 自动换行开关、状态栏实时显示行/列/选中长度/字符数。

### F3 语法着色（代码语言）
- F3.1 支持语言：C/C++、C#、Java、JavaScript/TypeScript、Python、Go、Rust、JSON、XML/HTML、CSS、Markdown 等（按扩展名识别）。
- F3.2 分词着色：关键字/控制流/字符串/注释/数字/类型/预处理/标签/属性。
- F3.3 彩虹括号：(), [], {} 按嵌套层级四色循环着色；超大文件（>300KB）自动跳过彩虹括号。
- F3.4 着色幂等：文本未变化时不做任何格式化操作，杜绝事件循环与闪烁。

### F4 智能提示（VS 风格）
- F4.1 标识符前缀 ≥2 字符触发；候选来自语言关键字 + 全文档标识符索引。
- F4.2 弹层显示最多 12 条候选，键盘上下/翻页选择，回车/Tab 接受。
- F4.3 唯一候选等于已输入词时不弹窗（VS 同款行为）。
- F4.4 打字过程中候选列表增量过滤，内容未变化时复用弹层不重建（防闪烁）。
- F4.5 格式化：Ctrl+K,Ctrl+D 文档格式化 / Ctrl+K,Ctrl+F 选区格式化（两段式快捷键）。

### F5 主题
- F5.1 默认水墨主题（宣纸底/墨黑字/朱砂点缀），附 Ant.Light/Ant.Dark。
- F5.2 切换主题即时生效：编辑区、标签区、状态栏、智能提示弹层全部同步换色并重新着色。

### F6 稳定性与分发
- F6.1 全局异常捕获：崩溃时写 %LOCALAPPDATA%\TaoPad\crash.log 并弹窗提示，不再"无声无息"。
- F6.2 一键打包 build-installer.bat → MSI（WiX 5）+ EXE 安装器（含自包含运行库，无需联网）。
- F6.3 覆盖安装：版本号必须随发布递增，MajorUpgrade 自动清理旧版本。

## 非功能需求
- 性能：5 万行文本编辑不卡顿；着色防抖 220ms；>300KB 跳过彩虹括号。
- 可诊断：所有静默失败均有注释说明与兜底路径；崩溃可从日志定位。
- 安装：微信风格单页安装向导（协议勾选 + 目录 + 文件关联选项）。

## 约束
- .bat 文件必须 GBK 编码 + CRLF 换行（Windows cmd 兼容）。
- 源码 .cs/.xaml/.wxs/.csproj 必须 UTF-8 BOM。
- 命名使用简短英文语义化词，避免冗长前缀。
